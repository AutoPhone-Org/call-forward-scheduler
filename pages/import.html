配置导入说明

通过 Deep Link 将网页端录入的人员、转移类型与排班表一键导入 App。

Deep Link 协议

App 通过 callforward Scheme 接收配置，链接格式如下：

callforward://import?config=<URL 安全的 Base64 编码的 JSON>

其中 config 为固定参数名，值为配置 JSON 经 UTF-8 安全 Base64 编码后再 encodeURIComponent 的结果。

JSON 结构

{
  "people": {
    "姓名": "手机号"
  },
  "forwardType": "unconditional",
  "roster": [
    {
      "date": "2026-09-28",
      "assignments": [
        { "shift": "白班", "person": "思源" }
      ]
    }
  ]
}
  • people：姓名到手机号的映射，键为姓名、值为手机号。
  • forwardType：转移类型，可选 unconditional（无条件）、busy（遇忙）、noanswer（无应答）、unreachable（不可及）。
  • roster：排班表数组，每项含 date（ISO 日期）与 assignments（该日的班次指派）。

班次名称

默认支持以下班次名：全天、白班、夜班、早班、中班、晚班。

编码规则

为保证中文等非 ASCII 字符正确传输，需使用 UTF-8 安全的 Base64 编码，推荐实现如下：

// JavaScript 端
var json = JSON.stringify(config);
var encoded = encodeURIComponent(btoa(unescape(encodeURIComponent(json))));
var url = "callforward://import?config=" + encoded;

App 端将按约定对 config 执行 decodeURIComponent 后 Base64 解码，还原为原始 JSON。

等价方案：也可使用标准 base64url 编码，但必须确保 App 端解码逻辑与此一致。推荐直接使用上述 UTF-8 安全 Base64 方案。
