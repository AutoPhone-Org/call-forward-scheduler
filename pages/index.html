功能特性

为轮班团队打造的电话值守方案

无需 root，无需手动拨号，排班一到自动切换呼叫转移目标。

定时倒班切换

按排班表在指定时刻自动切换呼叫转移目标，无人值守也能精准交接。

多班次排班

内置两班倒、三班倒、四班两倒、四班三倒模板，支持全天、白班、夜班等班次与每日多切换节点。

无 Root 转移

经 Shizuku 以 shell 权限下发 USSD 指令，无需 root 即可完成呼叫转移。

一键取消

随时一键取消全部转移，避免漏接来电，测试切换安全无忧。

配置导入

在网页端录入人员与排班，生成 Deep Link 一键导入 App，免去手机端重复填写。

稳定可靠

基于精确闹钟与开机恢复，排班任务持久可靠，重启后自动重建调度。

使用步骤

三步开启自动呼叫转移

从配置到值守，全程几分钟即可完成。

1

安装并激活 Shizuku

在手机安装 Shizuku 并通过无线调试或 root 方式激活，为 App 提供 shell 权限。

2

配置人员与排班

在下方编辑器录入人员与手机号映射、转移类型与每日排班表，生成导入链接。

3

导入并一键转移

点击「导入到 App」唤起应用完成配置，授权后即可设置或随时取消转移。
